# Winter Night

A winter night theme for the Claude desktop and mobile apps. A snowy pine forest sits under a moonlit sky, and snow keeps falling. The snow comes down harder and piles higher as you get closer to your usage limit. Near 100%, the drift buries the trees and the cabin.

- `/snow 75` previews the scene at 75%.
- `/snow live` makes the snow follow your real usage again.
- The status line shows the current level, and a toast warns you once you pass 90%.

## Install

At the prompt of a Claude Code terminal session:

```
/plugin install winter-night --marketplace tritledamon-netizen/Christmas-at-night
```

From a shell:

```
claude plugin install winter-night --marketplace tritledamon-netizen/Christmas-at-night
```

In the Claude desktop app: click **+** next to the prompt box, then **Plugins**, then **Add marketplace** with `tritledamon-netizen/Christmas-at-night`, then **Add plugin**.

This repository is private, so installing needs a GitHub credential for github.com on the machine (an SSH key, or `gh auth login` then `gh auth setup-git`).
